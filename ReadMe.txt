Android Login App

This is a simple Android application that includes essential user authentication features such as login, account registration, and password recovery.

Features

• Login: You can log in using the admin username and password.
• Create New Account: On the login screen, there’s a “Register” link that takes you to the registration page where you can create a new account.
• Forgot Password: If you forget your password, click the “Forgot Password” link to reset it.
• Welcome Page: After a successful login, you’ll be redirected to the “Welcome” screen.
• Reset Button: The login screen also includes a “Reset” button that clears the entered username and password fields.

How the App Works (Navigation Flow)

Login Screen:
• When the app is launched, the first screen displayed is the login screen.
• From here, you can log in, create a new account, or reset your password.

Successful Login:
• If the entered username and password are correct, you’ll be redirected to the Welcome Page.

Failed Login:
• If the username or password is incorrect, the message “Invalid username or password” will appear on the screen.

Navigating to Other Screens:
• Register: Clicking the “Register” link takes you to the Registration Page.
• Forgot Password: Clicking the “Forgot Password” link takes you to the Password Reset Page.
